## Souhrn epiku

Epic 5 dokončil 5 z 5 stories zaměřených na produkční kvalitu formulářového systému: globální readOnly režim s propagací do všech 22 widgetů, state integrity (zachování focusu a kurzoru při asynchronních aktualizacích), kompletní a11y audit podle WCAG 2.1, keyboard interakce s CustomEvent architekturou, a dynamické stavy tlačítek (disabled/hidden) v JSON definici.

Poměr práce: 80% audit a konsolidace existujícího kódu, 20% nová implementace. Infrastruktura z předchozích epiců byla solidní základ.

Adversarial code review zachytil 1 HIGH, 3 MEDIUM a 2 LOW nálezů — všechny opraveny v jednom průchodu. Žádný CRITICAL.

## Co fungovalo dobře

- **Surgical update pattern** (Story 5.2) — `prevValuesRef`/`lastPropValuesRef` zajišťují synchronizaci jen změněných polí. Aktivní pole se nikdy nepřepíše z props. Žádná ztráta focusu ani kurzoru.
- **Guard-first pattern** konzistentní napříč epicem — readOnly blokuje klávesnici (5.1), disabled blokuje submit (5.5), hidden odebírá z DOM (5.5). Validace probíhá PŘED akcí.
- **CustomEvent("form-key-action")** scoped na `formRef.current` — čistá izolace formulářů, žádný cross-form interference.
- **getDateLocale() utility** extrahovaná po code review — single source of truth pro locale mapping, eliminace `import * as Locales` double-castů.
- **ReadOnly ≠ Disabled** — čisté UX rozhodnutí. ReadOnly pole zůstávají čitelná (`bg-muted/50`), ne zašedlá.
- **Hidden via filter, ne CSS** — hidden tlačítka kompletně odstraněna z DOM, layout se korektně posune.
- **isSubmitting jako globální override** — během submission jsou VŠECHNA tlačítka disabled.
- **153 testů** ve 22 test souborech — silné pokrytí.
- **stories-5.test.tsx** jako centrální integrační test file napříč stories — efektivní organizace.
- **ARIA audit** všech 22 widgetů odhalil a fixnul mezery.

## Co nefungovalo dobře

- **Locale double-casts** — `date-widget.tsx` a `datetime-widget.tsx` používaly `(Locales as Record<string, Locale>)[localeName] as Locale`. Mělo být extrahováno do utility funkce od začátku. Zachyceno až v code review jako HIGH finding.
- **`aria-readonly` chyběl** na date, datetime a textarea widgetech — explicitní atribut nutný pro konzistenci se ARIA specifikací. Zachyceno jako MEDIUM.
- **File input `aria-label` chyběl** — skrytý file input (`className="sr-only"`) bez `aria-label` je pro screen readery neviditelný. Zachyceno jako MEDIUM.
- **Datetime time input `aria-label`** — `<input type="time">` neměl explicitní `aria-label="Time"`. LOW finding, ale důležitý pro screen readery.
- **Stále nemáme UI integration testy** (React Testing Library) pro end-to-end flows — spoléháme na unit testy widgetů a store.
- **Epic 5 je poslední definovaný epic** — pro další práci je třeba definovat nové epics.

## Klíčové technické poznatky

### Vzory, které se osvědčily

- Guard-first pattern v readonly/disabled/hidden — všechny validace PŘED akcí, neúspěšné operace nevytvářejí side efekty.
- Surgical update pattern s `document.activeElement` → `closest("[data-field]")` — efektivní detekce aktivního pole bez re-renderu.
- CustomEvent architektura pro keyboard akce — widget → event → form handler → action execution. Čistá separace concerns.
- Sdílená utility funkce (`getDateLocale()`) jako single source of truth — vzor z `VALID_FIELD_KEY` regex z Epicu 4.
- ARIA atributy jako first-class requirement — `aria-invalid`, `aria-required`, `aria-readonly`, `aria-describedby` na každém widgetu.

### Rizikové oblasti

- A11y u custom widgetů vyžaduje explicitní `aria-label` i na skrytých/sr-only elementech.
- Locale mapping by měl být vždy centralizován — duplicitní cast patterny jsou code smell.
- `relationship-widget.tsx` se blíží hranici 300 LOC — kandidát na modularizaci v budoucnosti.
